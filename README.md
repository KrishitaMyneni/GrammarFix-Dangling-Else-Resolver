# GrammarFix — Dangling-Else Resolver

A compiler design project that detects dangling-else ambiguity in nested if-else statements and resolves it using matched and unmatched grammar transformations.

## Problem Statement

The dangling-else problem occurs when an else clause can be associated with multiple unmatched if statements, creating ambiguity in a grammar.

## Features

- Tokenization of nested if-else statements
- Dangling-else ambiguity detection
- Original ambiguous grammar
- Matched and unmatched grammar transformation
- Competing parse tree generation
- Nearest-unmatched-if resolution
- Invalid syntax handling
- Parse tree visualization
- Nested if-else test cases
